# Smart Resource Allocation Using Banker's Algorithm

## Overview
A C-based resource allocation simulator using Banker's
Algorithm to check system safety and validate requests.

## Features
- Displays resource allocation matrices.
- Calculates the Need matrix.
- Detects safe and unsafe states.
- Finds a safe execution sequence.
- Validates process resource requests.
- Rejects requests that would make the state unsafe.

## Project Structure
- docs/ - Algorithm and project documentation.
- reports/ - Project reports.
- results/ - Program results.
- src/ - C source code.
- tests/ - Automated tests.
- Makefile - Build and test commands.
